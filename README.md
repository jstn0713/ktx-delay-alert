# KTX 지연 알림

내가 타는 KTX가 **몇 분 늦게 오는지**를 휴대폰 **상단 알림바에 계속** 보여주는 안드로이드 앱입니다.

- 요일별로 타는 열차를 등록해 두면, 출발 **60분 전부터** 자동으로 지연 정보를 확인합니다.
- 상단바에 `7분 지연 · KTX-산천 352 (20:12)`처럼 계속 표시하고, 내 역을 떠나고 **5분 뒤** 자동으로 사라집니다.
- 처음 지연이 생기거나, 지연이 **3분 이상** 바뀌거나, 운행이 취소되면 **소리·진동**으로 알려줍니다.
- 내릴 역 **도착 예상 시각**도 함께 보여줍니다. (지금 지연이 그대로 이어진다고 보고 계산한 값)
- 홈 화면 **위젯**, **오늘은 끄기** 버튼, 날마다 쌓이는 **지연 기록·통계**가 있습니다.

> 지연 정보는 **네이버 지도의 기차 조회**에서 가져옵니다(네이버가 코레일과 제휴해 받는 데이터). 공식으로 공개된
> 기능이 아니라 개인용으로만 쓰며, 네이버가 바꾸면 갑자기 안 될 수 있습니다. 실제 운행 정보는 항상 코레일·네이버
> 안내를 우선해 주세요.

---

## 1. 휴대폰에 설치하기

1. 휴대폰 인터넷(크롬 또는 삼성 인터넷)으로 아래 주소를 엽니다.
   **https://github.com/jstn0713/ktx-delay-alert/releases/latest**
2. 아래쪽 **Assets**에서 `ktx-delay-alert.apk`를 눌러 내려받습니다.
   - "이 파일은 기기를 손상시킬 수 있습니다" 같은 경고가 나오면 **그래도 다운로드**를 누르세요.
3. 다운로드가 끝나면 알림에서 파일을 누르거나, **내 파일 → 다운로드**에서 `ktx-delay-alert.apk`를 누릅니다.
4. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켜고 뒤로 가서 **설치**를 누릅니다.
5. 설치가 끝나면 **열기**를 누릅니다.

## 2. 처음 한 번만 하는 설정

앱을 열면 홈 화면 맨 위에 빨간 카드로 필요한 설정이 나옵니다. 위에서부터 눌러 주세요.

1. **알림 허용** → "허용"
2. **배터리 제한 없음으로** → "허용"
   - 삼성폰은 배터리 절약 때문에 앱을 잠재워서 알림이 늦거나 안 올 수 있습니다. 꼭 해주세요.
   - 창이 안 뜨면: 설정 → 애플리케이션 → KTX 지연 알림 → 배터리 → **제한 없음**
3. (나오는 경우만) **알람 권한 허용**

모든 설정이 끝나면 빨간 카드가 사라집니다.

## 3. 타는 열차 등록하기

아래 **열차** 탭 → 오른쪽 아래 **+** 버튼을 누릅니다.

1. **타는 요일**: 동그라미를 눌러 고릅니다. 여러 개를 골라도 됩니다.
2. **구간**: 타는 역 `천안아산`, 내리는 역 `수서`를 입력합니다.
3. **열차 번호**(예: `352`)를 넣고 **번호 확인**을 누릅니다. 네이버에서 바로 조회해 열차 이름과 출발·도착 시각을
   자동으로 채워주고, 조회가 잘 되는지도 그 자리에서 확인됩니다.
   - 번호를 모르면 **네이버 지도**에서 그 구간·시각을 검색해 KTX 번호를 확인하세요.
4. **저장**을 누릅니다.

예시 (같은 날 여러 열차를 모두 보고 싶으면 **각각** 추가하세요):

| 요일 | 출발 | 구간 | 열차 |
|---|---|---|---|
| 일 | 12:49 | 천안아산 → 수서 | KTX-산천 324 |
| 수 | 19:45 | 천안아산 → 수서 | (네이버에서 번호 확인) |
| 수 | 19:54 | 천안아산 → 수서 | (네이버에서 번호 확인) |
| 수 | 20:12 | 천안아산 → 수서 | KTX 352 |
| 목 | 18:05 | 천안아산 → 수서 | KTX-산천 346 |

## 4. 잘 되는지 확인하기

**홈** 탭 아래쪽 **네이버 조회 테스트** → 열차 번호를 넣고 **지금 조회**를 누릅니다.

- 역별 예정 시각과 지연이 나오면 정상입니다. 네이버 지도의 기차 지연 정보와 비교해 보세요.
- 숫자가 다르거나 오류가 나오면 **원본 복사**를 눌러 복사한 내용을 개발 대화창에 붙여 넣어 주세요.

## 5. 쓰는 방법

- **자동 시작**: 등록한 요일, 출발 60분 전이 되면 상단바에 표시가 생깁니다. 앱을 열어둘 필요가 없습니다.
- **확인 간격**: 평소 2분마다, 출발 30분 전부터는 1분마다 확인합니다.
- **상단바 알림을 아래로 당기면** 열차별 지연과 도착 예상 시각이 보입니다.
  - **지금 확인**: 바로 다시 조회
  - **오늘은 끄기**: 오늘 하루 확인을 멈춤 (앱 홈 화면에서 "오늘 다시 켜기" 가능)
- **위젯**: 홈 화면 빈 곳을 길게 누름 → 위젯 → "KTX 지연 알림"
- **기록** 탭: 열차별 평균 지연, 지연된 날 수, **지연 정보가 출발 몇 분 전에 처음 떴는지**를 보여줍니다.
- **설정** 탭: 확인 시작 시각, 확인 간격, 알림 기준(분)을 바꿀 수 있습니다.

## 6. 새 버전으로 업데이트

새 버전이 나오면 앱 홈 화면 맨 위에 **새 버전이 있어요** 카드가 나옵니다.
**새 버전 다운로드**를 눌러 받은 파일을 열고 **업데이트**를 누르면 됩니다. 등록한 열차와 기록은 그대로 유지됩니다.

## 7. 문제가 생기면

| 증상 | 해결 |
|---|---|
| 상단바에 아무것도 안 뜸 | 홈 화면 빨간 카드의 설정을 모두 했는지 확인. 알림 설정에서 "실시간 지연 표시"가 켜져 있는지 확인 |
| 늦게 뜨거나 중간에 사라짐 | 배터리 **제한 없음** 설정 확인. 설정 → 배터리 → 백그라운드 사용 제한 → "절전 예외 앱"에 추가 |
| "이 번호의 열차가 조회되지 않아요" | 열차 번호·운행 요일 확인. 열차 수정 화면에서 **번호 확인**으로 다시 확인 |
| "네이버가 데이터 대신 페이지를 보냈어요" 등 | 네이버가 조회 방식을 바꿨을 수 있어요. 개발 대화창에 알려주세요 |

## 개발자용 메모

- 안드로이드 네이티브 앱 (Kotlin, Jetpack Compose). 최소 Android 8.0, 대상 SDK 35
- `main` 브랜치에 올라가면 GitHub Actions가 테스트 → APK 빌드 → **Releases**에 자동 게시합니다.
- 버전 번호는 `1.0.<빌드 번호>`입니다.
- 서명 키는 어디에도 저장하지 않습니다. 저장소 Secret **`SIGNING_SEED`**(24자 이상 비밀 문구)로부터
  `.github/scripts/make_keystore.py`가 빌드 때마다 **항상 같은 키**를 만들어 서명합니다.
  Secret이 없으면 임시 키로 빌드만 하고 Releases에는 올리지 않습니다.
  **`SIGNING_SEED`를 바꾸거나 지우면 기존 앱 위에 업데이트 설치가 안 되니 절대 바꾸지 마세요.**
- 코드 구성
  - `core/` — 네이버 조회·응답 해석(`Naver.kt`), 감시 일정·알림 판단(`Monitor.kt`), 통계, 저장 형식. 안드로이드와 무관한 순수 Kotlin이고 단위 테스트가 있습니다.
  - `service/` — 출발 전 감시하는 포그라운드 서비스, 정확한 알람 예약, 알림 표시
  - `widget/` — 홈 화면 위젯
  - `ui/` — 화면 (홈, 열차, 기록, 설정)
- 데이터 출처: 네이버 지도 기차 조회 `pt.map.naver.com/end-train/api/train-time` (POST, 로그인·키 불필요, 익명 쿠키만).
  본문은 `{"runDate":"YYYYMMDD","trainNumber":"00352","railwayCompany":"KORAIL"}`, 역별 지연은 응답 `stopList[].actualArrivalDelayTimeNumber`(분)입니다.
  `NaverClient`가 먼저 페이지를 한 번 열어 쿠키를 받고 호출하며, 앱의 "네이버 조회 테스트"에서 원본 값을 확인할 수 있습니다.
  공식 공개 API가 아니므로 개인용으로만 사용합니다.
